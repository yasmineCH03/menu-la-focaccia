# Menu en ligne — Pizzeria La Focaccia

Menu accessible par QR code, en français et en anglais, publié avec GitHub Pages depuis le dossier `docs/`.

## Modifier le menu
1. Changer un plat ou un prix dans `prototype/menu.json` (traductions anglaises dans `prototype/en.json`).
2. Régénérer le site : `python prototype/build.py` (nécessite Pillow).
3. Committer et pousser : GitHub Pages se met à jour tout seul.
